Release Notes — Simple Bank Account (Java CLI)
v1.1 — Withdrawal Validation & Transaction History
Release Date: November 25, 2026
New Features & Improvements
Withdrawal with Balance Validation: Added withdraw functionality with checks to prevent withdrawals exceeding the current account balance or using invalid amounts.
Transaction History: Added tracking and display of account transactions (such as deposits and withdrawals) so users can review their activity.
Branching, Merging & Conflict Resolution
Developed new features on dedicated feature branches (features/withdraw-checks and transaction history updates) before integrating them into main.
Resolved merge conflicts manually in BankAccount.java and Main.java to combine withdrawal checks and transaction history cleanly on the main branch.

Implemented core BankAccount and Main CLI functionality supporting account deposits and balance checking.
