# Simple Bank Account (Java CLI)
A lightweight Java command-line banking simulator demonstrating core software congiguaration management (SCM) practices including branching , merge conflict revolution , and semantic release tagging .
## Features (v1.0)
- **Deposite Funds :** Add positive amounts to the account balance 
- **Chech Balance :** View the account holders name and current balance .

## How to run 
Make sure you have Java (JDK) installed , then run : 
```bash
javac BankAccount.java Main.java 
java Main 
```
